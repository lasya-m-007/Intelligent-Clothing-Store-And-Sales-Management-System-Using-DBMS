# IntelliWear – Smart Clothing Store Management System

IntelliWear is a full-stack web application developed using Flask, MySQL, HTML, and CSS to efficiently manage clothing store operations. The system provides a secure login mechanism using session-based authentication, ensuring that only authorized users can access the application. Once logged in, users are presented with a dashboard that displays key business insights such as total products, total sales, total revenue, and low-stock items, along with quick action buttons for navigation. The product management module allows users to add, update, and delete products while maintaining details such as name, category, price, and stock, with visual indicators for low inventory levels. The sales module enables users to search for products using their ID, generate bills based on quantity, and automatically update stock after each transaction, while also maintaining a complete sales history for tracking purposes. The application features a modern, responsive user interface with a sidebar navigation system, card-based dashboard, styled tables, and forms, making it user-friendly and visually appealing. Overall, IntelliWear simplifies inventory management, billing, and sales tracking, helping clothing store owners operate their business more efficiently through a centralized digital platform.
